# /crear-readme

1.  **Generar Estructura**
    *   Crea `README.md` con las secciones estándar:
        - Hero (Título, Slogan, Badges, Imagen)
        - Tabla de Contenidos
        - Características (Tabla)
        - Instalación / Uso
        - Arquitectura (Mermaid)
        - Tecnologías
        - Contribuir
        - Licencia

2.  **Badges**
    *   Usa estilo: `style=flat-square`.

3.  **Contenido**
    *   Rellena con información del contexto actual del proyecto.
